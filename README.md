# Gemella morbillorum and colorectal cancer

This repository contains the computational analyses associated with our study investigating the potential role of *Gemella morbillorum* in colorectal cancer progression.

## Analyses

1. Public metagenomic and machine-learning analysis
2. RNA-seq analysis of HCT116 colorectal cancer cells infected with *Gemella morbillorum*
3. TCGA candidate-gene survival analysis

## Repository structure

- `01_public_metagenome/` — public metagenomic and machine-learning analyses
- `02_hct116_rnaseq/` — HCT116 RNA-seq analysis
- `03_tcga_survival/` — TCGA candidate-gene survival analysis

Detailed instructions for each analysis are provided in the corresponding subdirectory.
